# Instructions for AI Agents (AGENTS.md)

This repository is part of the **Antigravity Agent Ecosystem** managed by TheNovaNodes.

When working on this codebase, AI agents should adhere to the following guidelines:

1.  **Language:** All code comments, documentation, and commit messages must be in high-quality English.
2.  **Code Style:** Follow standard Python conventions (PEP 8).
3.  **Testing:** Maintain or improve test coverage. Run tests using `python -m pytest tests/` before submitting changes.
4.  **Verification:** Always verify file operations and test execution.
5.  **No LLM Synthesis:** This gateway is designed to return raw data. Do not add LLM-based synthesis to the search results returned by the MCP tools.
