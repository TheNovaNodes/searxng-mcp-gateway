# Contributing to searxng-mcp-gateway

Thank you for your interest in contributing to the **Antigravity Agent Ecosystem**!

## How to Contribute

1.  **Fork the repository:** Create your own fork of this project.
2.  **Create a branch:** Make your changes in a feature branch.
3.  **Write Tests:** Ensure any new features or bug fixes are accompanied by tests.
4.  **Run Tests:** Execute the test suite (`python -m pytest tests/`) and ensure all tests pass.
5.  **Submit a Pull Request:** Describe your changes clearly in the PR description.

## Code Standards

- All code and documentation must be in high-quality English.
- Follow PEP 8 guidelines for Python code.
- Ensure backwards compatibility with existing MCP tools.

## Support TheNovaNodes

If you find this repository helpful, consider supporting our infrastructure and the development of new open-source integrations.
